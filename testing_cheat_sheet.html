⚡ Testing Commands & Usage
Command Tool Used What It Does
npm run test Vitest Runs all Unit & Integration tests once in the terminal. Shows quick pass/fail results.
npm run test:watch Vitest Watch Runs Unit tests in live mode. Automatically re-tests affected files instantly when you press Ctrl+S.
npm run test:e2e Playwright Runs System & UAT browser tests invisibly in the background across Chrome/Safari.
npm run test:e2e:ui Playwright UI Opens an interactive visual window to step through browser tests, time-travel, inspect network calls, and debug errors.
🛠 Testing Tools & Their Roles
Vitest
Fast Vite-native test runner for Unit and Integration tests. Replaces legacy Jest with instant ESM execution.
Playwright
End-to-End browser automation framework. Simulates real users interacting with Chrome/Firefox/Safari browsers.
React Testing Library
Renders React components in memory to test button clicks, inputs, and DOM output as users see them.
jsdom
In-memory browser DOM emulator that allows fast unit testing without needing to launch a full web browser window.
